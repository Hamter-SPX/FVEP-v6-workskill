# Voxel sandbox (Minecraft-class)

Block world, gather/craft/build, exploration, and optional multiplayer servers.

## Content pillars

- Block palette and crafting graph
- Chunk generation / biomes
- Building and destruction as core verbs
- Mobs, day/night, survival meters (if survival mode)
- Mods/datapacks or addon surface (project-dependent)

## Graphics default

Start from [`../graphics/voxel-block.md`](../graphics/voxel-block.md). Variants may add smooth lighting or resource packs without leaving block identity.

## UI/UX hotspots

- Hotbar + inventory crafting grid
- Pause / settings that work in survival stress
- Server list / world select (if multiplayer)
- Crosshair and block-break feedback

## Tools / plugins (examples of class)

- Map editors, schematic tools
- Server plugins/mods (auth, economy, protection)
- Resource-pack pipelines

Open with [`../systems/assets-pipeline.md`](../systems/assets-pipeline.md), [`../systems/ui-hud.md`](../systems/ui-hud.md), [`../systems/tools-plugins.md`](../systems/tools-plugins.md).
