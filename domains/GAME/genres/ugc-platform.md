# UGC platform experiences (Roblox-class)

Experiences built on a shared platform: avatars, catalog, social, and creator tools matter as much as your level design.

## Content pillars

- Onboarding inside platform UX + your experience UX
- Avatar-ready characters and animations
- Monetization surfaces (passes, catalog) if used — clear and non-deceptive
- Social: friends, parties, servers/instances
- Creator constraints (physics, instance limits, networking model of the platform)

## Graphics default

Start from [`../graphics/ugc-avatar-platform.md`](../graphics/ugc-avatar-platform.md). Stylized or low-poly sets are fine if they fit modular avatars.

## UI/UX hotspots

- Shop / unlock clarity
- Mobile touch + gamepad if platform requires
- Safe chat / report entry points when social
- Loading and teleport between places
