# Performance and platforms

## Budgets to declare early

- Frame time (30/60/120)
- CPU main / render / job threads
- GPU, memory, streaming stall limits
- Download / install size
- Thermals on mobile

## Platform packs

- Console certification checklists (TRCs/TCRs-class — project-specific)
- PC: settings scalability tiers
- Mobile: device tiers and backgrounding

Profile with evidence; do not claim “optimized” without numbers.
