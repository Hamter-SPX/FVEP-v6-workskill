# UI / HUD (games)

Game UI must stay readable while the world moves.

## Checklist

- Primary task visible under motion blur / camera shake
- HUD hierarchy: critical > useful > optional
- Safe areas and ultrawide
- Colourblind-safe status (health, team, rarity)
- Menu vs gameplay input maps do not collide
- Localization length and font coverage

## Direction vs fidelity

- New look → `DESIGN/` + visual-direction exploration + distinctness gate
- Match locked mock → `ascii-map` / `layout-structure` / vision-loop
