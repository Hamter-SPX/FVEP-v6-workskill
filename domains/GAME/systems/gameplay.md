# Gameplay systems

Rules, controllers, and content data that define play.

## Common modules

- Player controller and camera
- Combat / interaction
- AI directors or behavior trees
- Mission / quest graph
- Inventory and economy tables
- Save / checkpoint identity
- Cheat / debug overlays (dev only)

## Evidence habits

- One change → one falsifiable playtest claim
- Balance numbers live in data tables, not buried magic constants when tunable
- Replay or seed notes for bug reproduction

Ties to GENERAL scientific debugging when feel bugs appear.
