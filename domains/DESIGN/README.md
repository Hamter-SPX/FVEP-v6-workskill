# DESIGN

Domain pack for visual direction, craft, and brand expression across games and applications.

## Core chain

1. Explore options 1/2/3 — `../../references/visual-direction-exploration.md`
2. Gate distinctness — `npm run direction:distinctness`
3. Spec → confirm (เริ่มเขียน / ปรับต่อ / เลือกใหม่)
4. Bind aesthetic profile — `../../references/aesthetic-direction-protocol.md`
5. Measure craft — colour, type, spacing, motion, style signature

## When DESIGN owns the turn

- Screenshot redesign / restyle
- Brand personality and novelty budget
- Choosing a look before implementation

## When to hand off

- After **เริ่มเขียน** → APPLICATION or GAME implementation packs
- Pixel match to a locked reference → `ascii-map` / `layout-structure` / vision-loop (fidelity mode), not new direction exploration
