# Threat Model Review Prompt

Identify assets, actors, entry points, trust boundaries, privilege transitions, tenant boundaries, sensitive data, secrets, files, outbound requests, dependencies, and business abuse cases. Build a subject × action × resource × context authorization matrix and negative-test plan. Review input constraints, output encoding, CSRF, SSRF, uploads, rate limits, audit, encryption, retention, and incident detection. Treat static findings as indicators, not proof of absence.
